# Duolingo UI Research Sources

*(as of 2026-11-04)* — gathered for rebuilding Duolingo-style UIs (halolesson workspace).

- **open-design Duolingo DESIGN.md** — most complete token spec (colors, type, components, spacing, motion, guardrails): https://github.com/nexu-io/open-design/blob/main/design-systems/duolingo/DESIGN.md
- **Kairaxis Duolingo Styleguide prompt** — 184-line implementation-ready spec: exact px values for navbar, hero, 8 panels incl. dark theme, responsive breakpoints at 900px/600px: https://www.kairaxis.com/prompts/duolingo-styleguide-hero
- **Norrly duolingo.com breakdown** — measured live-site palette + vibe-coding prompt principles: https://norrly.io/inspiration/duolingo-com
- **Official brand docs**: https://design.duolingo.com/ (identity/color)
- **DesignSystems.one Duolingo reference** (medium confidence, restated): https://www.designsystems.one/design-systems/duolingo-design
- **Example rebuild project** (plain HTML/CSS/JS exercise UI): https://github.com/KasraTabrizi/duolingo-exercise-project
