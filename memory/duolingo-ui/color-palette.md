# Duolingo Color Palette

*(as of 2026-11-04)* — from open-design DESIGN.md, Kairaxis styleguide, Norrly breakdown. See [[duolingo-research-sources]].

## Primary (owl green family)
| Token | Hex | Role |
|---|---|---|
| Owl Green | `#58cc02` | brand primary, primary CTA, correct answer (30%+ of surface) |
| Owl Green Deep | `#58a700` | pressed/bottom-shadow color for green buttons |
| Owl Green Light | `#89e219` | hover, soft fills |
| Owl Green Pale | `#dbf8c5` | soft surface, success banner |

## Secondary accents
| Token | Hex | Role |
|---|---|---|
| Streak Orange | `#ff9600` | streak counter, fire icon |
| Streak Orange Deep | `#cc7a00` | pressed orange |
| Gem Pink | `#ce82ff` | gem currency, Super Duolingo |
| Eel Blue | `#1cb0f6` | hint buttons, info links, input focus |
| Cardinal Red | `#ff4b4b` | wrong answer, life lost (pressed `#cc3b3b`) |
| Bee Yellow | `#ffc800` | pro badge, achievement |

## Surface
- Snow `#ffffff` — primary background
- Eel `#f7f7f7` — section break / secondary surface
- Swan `#e5e5e5` — disabled bg, inset block, standard 2px border
- Dark blue `#100f3e` — alternate dark section surface

## Ink & text
- Eel Black `#3c3c3c` (some refs `#4b4b4b`) — primary text
- Wolf `#777777` — secondary text, captions
- Hare `#afafaf` — disabled, placeholder, emphasized border on hover

Key rule: 1–2 signature hues repeated everywhere; saturated green + orange + blue accents carry the identity. Never hairline borders — always 2px+.
