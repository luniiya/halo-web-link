## Gotchas
- Write/Edit is refused on a file not Read first; check the result (a silent failure once made "the ui barely change").
- markup.test.ts: every `#id` in styles.css must exist in the rendered markup, and there must be >5 of them.
- No arrow glyphs (←→ etc.) in UI sources; use SVG icons.
- Shell is fish: quote globs like `--include='*.js'`.
- perl unicode replace needs `-CSD` and `\x{2014}`; `\s*` eats newlines.
