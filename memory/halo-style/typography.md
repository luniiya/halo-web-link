# Halo typography

*(as of 2026-11-07)* Font: **Nunito** (`"Nunito", "Avenir Next", system-ui, sans-serif`), loaded from Google Fonts
with weights 400;600;700;800;900;1000 (`display=swap`, preconnect to fonts.googleapis.com + fonts.gstatic.com).

- Headings and titles: weight 900 ("font-black"), text ink.
- Buttons, nav items, eyebrows: 900, UPPERCASE, slight tracking.
- Body/labels: 600-800; muted text uses wolf.
- Rounded, friendly, heavy. Never thin weights.
